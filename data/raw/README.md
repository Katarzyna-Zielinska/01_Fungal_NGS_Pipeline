# Raw sequencing data

The raw sequencing data are not included in this repository because the
sequencing files exceed GitHub's file size limits.

The paired-end sequencing files used in this project are:

-   `SRR10059687_1.fastq`
-   `SRR10059687_2.fastq`
-   `SRR10059688_1.fastq`
-   `SRR10059688_2.fastq`
-   `SRR10059689_1.fastq`
-   `SRR10059689_2.fastq`
-   `SRR10059690_1.fastq`
-   `SRR10059690_2.fastq`
-   `SRR10059691_1.fastq`
-   `SRR10059691_2.fastq`
-   `SRR10059692_1.fastq`
-   `SRR10059692_2.fastq`

Archive (SRA) or the European Nucleotide Archive (ENA) using the
accessions below.
